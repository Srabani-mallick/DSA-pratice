# Linked List Implementation

This project contains a basic implementation of a Linked List in Python. It was created to understand the fundamental concepts of linked lists and how nodes are connected dynamically.

## Requirements

- Python 3.x

## Run the Program

```bash
python linked_list.py
```

## Example Output

```text
10 -> 20 -> 30 -> 40
```

## Purpose

This project was developed as part of learning Data Structures and Algorithms (DSA) and to gain hands-on experience with linked list operations.
